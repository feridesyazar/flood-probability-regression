# Flood Probability Prediction with Regression

A machine learning project for predicting `FloodProbability` using environmental, infrastructure, planning, and socio-economic features.

## Project Overview

The project compares Linear Regression and HistGradientBoosting Regressor for predicting continuous flood probability values.

Model performance is evaluated using:

- R²
- RMSE
- MAE

Linear Regression achieved the better validation performance with:

- R²: 0.845
- RMSE: 0.0201
- MAE: 0.0158

## Dataset

Dataset: Kaggle Playground Series - Regression with a Flood Prediction Dataset

https://www.kaggle.com/competitions/playground-series-s4e5

## Models

- Linear Regression
- HistGradientBoosting Regressor

## Workflow

Data Exploration → Correlation Analysis → Feature Preparation → Train/Validation Split → Modelling → Evaluation → Final Prediction
